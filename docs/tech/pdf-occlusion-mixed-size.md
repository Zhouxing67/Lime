# PDF 遮挡/滚动谜题 —— 混合页尺寸 + 陈旧 scale 守卫 + 闭包陈旧值

## 症状（多轮 saga）
1. 右卡片面板"遮挡"PDF；拖拽方向反转
2. 最小面板也遮挡；左右拖动行为诡异
3. F12 打开时拖动才可能遮挡，全屏不遮挡

## 根因（每轮一个）
| 轮 | 根因 | 修复 |
|---|---|---|
| 1 | 面板**右锚定**（宽度从右缘量）但用左锚定 `+` 数学 → 拖拽方向反 | 改右锚定 `-` |
| 2 | `scale !== null` 守卫阻止**缩放重算**（面板变宽后页面保持旧宽 → 视觉遮挡）| scale 在 paneW 变化时重算（防抖 80ms）|
| 3 | 结构差异：旧版 PDF `flex: 0 0 55%` + 卡片 `flex:1` vs 新版 PDF `flex:1`——`flex:1` 在固定宽内容超宽时不可靠 | 回退 `flex: 0 0 78%` + 卡片 `flex:1` |
| 4 | **混合页尺寸**：文档级共享 scale 适配封面页 → 正文页（宽 31%）溢出 | **逐页缩放**：scale = paneW / 该页 baseW |
| 5 | F12 场景：**拖拽闭包持有陈旧 mainAreaW**（窗口变窄后与实际不符）| `maxPanelWRef` 实时读取 |

## 修复
- 右锚定拖拽数学 + 面板/主区矩形对比诊断（`panelLeft vs mainRight`）
- 逐页独立缩放（mixed-size PDF）
- 已加载页的尺寸键（`sizeKeyRef`）检测 zoom/paneW 变化 → 重算，解决缩放/拖动只影响未加载页

## 通用教训
- **视觉"遮挡"常是布局失效**（flex 基准、宽高约束）而非真的覆盖——用边界诊断日志（矩形对比）定位
- **flex 布局基准要可预测**（`flex-basis` 定值而非 `flex:1`）当内容宽度可能超过容器
- 混合尺寸文档：文档级共享比例必然溢出，逐元素缩放
- 拖动/缩放类交互的闭包要**读 ref 真值**而非 stale state
