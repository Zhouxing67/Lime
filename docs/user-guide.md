# Lime 使用文档

> Lime 是一款 Chrome 浏览器扩展，帮你**收集、整理、阅读和复习**知识——把网页摘录、PDF 批注、读书笔记沉淀为卡片，用间隔重复复习消化。

---

## 快速开始

1. 安装扩展后，工具栏出现 lime 图标。
2. 打开任意网页，选中一段文字，按 **`Alt+S`**——右侧弹出捕获侧栏，内容已填入。
3. 在「保存到」选择目标项目（或点 `＋` 新建项目），按「保存」。
4. 打开扩展管理页（点击 lime 图标），卡片出现在对应项目里。

---

## 界面总览

```
[导航栏] [侧边栏] [主工作区]                 [PDF卡片面板*]
  项目      项目树/    卡片网格 / PDF阅读      (*PDF 视图时)
  PDF       目录       / 复习 / 待办
  复习
  待办
  备份
```

- **最左导航栏**：五个视图（项目 / PDF 阅读 / 复习 / 待办 / 备份）+ 底部设置。
- **侧边栏**：随视图变化——项目视图显示项目树，PDF 视图显示目录/库。
- **底部栏**：状态信息（待办进度、同步状态、版本）。

## 一、网页捕获

捕获统一走**右侧捕获侧栏**：

| 操作 | 说明 |
|---|---|
| **`Alt+L`** | 打开捕获侧栏（不捕获内容）|
| **`Alt+S`** | 捕获——有选中文字捕获选中；悬停在公式上捕获公式所在段；悬停在图片上捕获图片 |
| **追加** | 侧栏开着且有内容时，`Alt+S` 把新捕获**追加**进草稿（公式/图片无法复制，这是它们的唯一追加路径）|
| **框选** | 侧栏图片输入行「框选」icon → 页面变暗 + 拖矩形 → 截图成为图片卡 |

### 捕获侧栏

- **保存到**：选择项目 / 新建项目。
- **摘要（可选）**：一句话概括。
- **内容**：捕获的正文（markdown 支持，公式 `$...$` 渲染）。
- **图片 URL**：粘贴图片链接回车插入；或点「框选」截取网页区域。
- **链接**：粘贴 URL，以摘要为标签插入 `[摘要](链接)`。

### 公式感知

悬停数学公式会出现半透明高亮；`Alt+S` 捕获公式所在整段（公式转为 `$...$` / `$$...$$`）。支持 KaTeX、MathJax、知乎等主流渲染。

## 二、项目与卡片

### 项目

- **项目树**（侧边栏）：最近优先，点击展开/收起（一次只展开一个）。
- 项目内分**章节**（L1/L2）：每张卡片属于一个项目的一个章节（或「未分类」）。
- 项目行 `＋` 添加章节；`⋯` 菜单重命名 / 编辑备注 / 删除。

### 卡片

- 卡片 = 一段捕获的知识：**摘要（title）+ 正文（content）+ 备注（idea）**。
- 悬停卡片：出现操作 icon（复制内容 / 移动到章节 / 加入复习 / 删除）。
- 点击卡片：打开详情（可编辑备注）。
- **批量模式**：顶栏「全选」→ 勾选多张 → 复制到项目 / 移动到章节 / 合并 / 删除。
- 卡片一旦创建就固定在其章节；跨项目用「复制到项目」。

### 整理

- 顶部面包屑 `项目 / 章节`：点击任一节点跳转；顶层显示全部卡片（同章节相邻）。
- 「移动到章节」把卡片移入目标章节（或移回未分类）。

## 三、PDF 阅读与批注

这是 Lime 的核心能力——在扩展内阅读 PDF + 批注 + 摘录卡片 + 回跳。

### 打开 PDF

1. 切到 **PDF 视图** → 侧边栏「打开 PDF」→ 选择本地 PDF 文件。
2. 侧边栏显示目录（TOC），点击跳转；工具栏可搜索全文、跳转页码、缩放（`Ctrl+滚轮`）。

### 批注 → 卡片（1:1）

| 批注 | 生成的卡片 |
|---|---|
| 选中文字 → 高亮 / 下划线 / 波浪线 / 删除线 | **文本摘录卡**（内容 = 引用原文）|
| 「框选」→ 拖矩形（公式 / 表格 / 图）| **图片卡**（截图，可 AI 识别）|

批注与卡片一一对应：**删批注删卡片，删卡片删批注**。

### PDF 卡片面板（右侧）

- 每张卡片 = 批注内容（只读引用块 / 框选图）+ 你的**备注（可编辑）**。
- 悬停卡片：复制内容 / 展开全文 / 编辑备注 / 置入项目。
- **点击卡片 → 跳回 PDF 原文**（滚动到批注位置并高亮居中）。
- **置入项目**：把 PDF 摘录卡放入项目（成为项目卡片，PDF 是来源）。底部显示「项目：XXX」，点击回到项目中的该卡。

### 其他

- **回跳历史**：工具栏 `↩` 返回上次阅读位置。
- **搜索全文**：跨页全文搜索，跳转 + 高亮。
- 批注点开可**改类型**（高亮↔下划线↔波浪线↔删除线）或删除。

## 四、复习（间隔重复）

Lime 内置 SM-2 间隔重复：到期卡片进入复习队列，科学安排复习时间。

1. 切到**复习视图** → 自动载入到期卡片。
2. 看正面 → 点卡片 / 空格翻面 → 看背面与原文。
3. 评分（三档）：

| 评分 | 含义 | 下次间隔 |
|---|---|---|
| **1 不认识** | 完全没记住 | 立即重学（1 天后）|
| **2 模糊** | 勉强想起 | ×1.3 |
| **3 认识** | 轻松答对 | ×1.6 |

- 键盘 `1` / `2` / `3` 快速评分。
- 同一天**首次评分**决定排程；重评只是练习。
- 卡片需先有**摘要**才能加入复习（卡片悬停「加入复习」）。

---

## 五、待办

- 待办是独立的卡片类型（不受项目隔离，全局可见）。
- 新建待办：待办视图的虚线瓦片；设置截止日期（按天，截止到当天 24:00）。
- **任务列表**：编辑待办时用「添加任务」——复选任务可勾选；保存后自动显示进度条。
- 待办按到期排序：已过期 / 今天到期 / 未来 / 无日期。
- 「清除已完成」把已完成任务隐藏（不删除）。

---

## 六、备份与同步

### 本地备份

- **备份视图** → 选「项目」或「PDF」范围 → 勾选 → 导出备份（ZIP：卡片 + PDF 文件 + 批注 + 复习）。
- 导入备份：备份视图「导入备份」→ 选 ZIP → 恢复。

### 坚果云同步

1. **备份视图** → 「坚果云同步」→ 填入 WebDAV 账号密码（存储在浏览器内）。
2. 点击**上传 / 下载**同步卡片、笔记、复习进度（PDF 文件也会同步）。
3. 云端冲突时：比较内容哈希，由你选择上传 / 下载。

## 七、设置

- **主题预设**：多套配色（浅 / 深色自动适配）。
- **悬停公式高亮**：开关公式感知高亮。
- 数据导出、版本信息。

## 快捷键速查

| 快捷键 | 作用 |
|---|---|
| `Alt+L` | 打开捕获侧栏 |
| `Alt+S` | 捕获（选区 / 公式段落 / 图片）；有草稿时追加 |
| `Ctrl+滚轮` | PDF 视图缩放 |

## 常见问题

**扩展更新后捕获/公式不生效？**
内容脚本只在页面加载时注入——**刷新网页**即可（或重新打开网页）。

**框选只能截屏幕可见区域？**
是——框选是屏幕截图，选区内必须可见（可先滚动到目标再框选）。

**删除项目会删除 PDF 摘录卡吗？**
不会——已置入项目的 PDF 卡会回到 PDF 视图（未分类），批注保留。

**复习的"已掌握"卡片还能重学吗？**
可以——卡片悬停「重新复习」即可。

**云同步的 PDF 在新设备是空的？**
同步只传笔记，PDF 文件需在新设备「打开 PDF」选择同一文件，批注自动关联。
